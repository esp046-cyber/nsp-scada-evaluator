    How to run an assessment

    1. Profile. Enter the vendor, project, capacity and the named 33kV connection point.
    2. Core criteria. Answer the four pillars: named 33kV NSP interface, IEC 61850 / DNP3 in live service, NSP-witnessed FAT/SAT/energisation, and prior NSP relationship. Each shows what auditors look for.
    3. 33kV point list. Mark each of the 10 demarcation signals as in scope, partial or not in scope.
    4. Evidence. Drop signed FAT/SAT sheets or single-line diagrams to log a SHA-256 hash for each.
    5. Final report. Review the verdict and export JSON, Markdown or a printed PDF.

    What is a critical blocker?

    A "High risk" verdict follows if criteria 1 to 3 are answered with anything short of full evidence, or if a required point is partial or not in scope. In-plant Modbus/OPC SCADA cannot stand in for a named utility-facing interface.

    How evidence hashing works

    Your browser computes a SHA-256 fingerprint of each file. If the file is changed later, its hash will differ, so the logged value shows which exact file you reviewed. The file never leaves your device and is not stored. Hashing needs https or localhost.
